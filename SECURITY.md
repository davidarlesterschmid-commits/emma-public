# Security Policy

## Public repository boundary

This repository must not contain credentials, private configuration, personal data, production endpoints, or confidential project material.

## Reporting a security concern

Do not open a public issue that contains sensitive information. Report security concerns through the repository maintainer's private security channel or GitHub's private vulnerability reporting feature if enabled.

## Supported content

Only curated public material is supported in this repository. Demo, mock, and stub examples must be clearly labeled and must not reference real persons, organizations, contracts, users, tickets, budgets, production systems, or private environments.
