# Contributing

## Before contributing

All changes must be suitable for a public repository. Do not submit confidential information, credentials, private links, personal data, production data, or internal project governance material.

## Contribution requirements

A contribution must:

- reference a tracked work item,
- describe its scope and non-scope,
- use only public, synthetic, anonymized, mock, demo, or stub material,
- avoid real people, organizations, contracts, customers, tickets, budgets, endpoints, and private systems,
- keep implementation work separate from governance and release decisions.

## Pull request expectations

Pull requests should explain:

- the purpose of the change,
- the files changed,
- public-readiness considerations,
- checks performed,
- known limitations.

Do not use public issues or pull requests to disclose sensitive information.
